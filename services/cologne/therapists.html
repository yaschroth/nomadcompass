Where these came from

All 368 come from one place, the Psychotherapeutenkammer NRW, the statutory psychotherapists' chamber of North Rhine-Westphalia. The statutory chamber of psychotherapists in North Rhine-Westphalia publishes a search of its members in which each one states the foreign languages therapy can be given in. We list what it prints for each therapist.

All 368 sit on an official list, the strongest tier this directory carries.

If none of these fits

If none of these fits, the nearest therapists we list are in Düsseldorf (119, 35 km away), Münster (90, 123 km away) and Frankfurt (1, 153 km away). Cologne itself also has 21 lawyers, 3 translators, 1 tax adviser and 1 dentist listed. A gap here means we have not found a source we can cite, not that nobody exists.
